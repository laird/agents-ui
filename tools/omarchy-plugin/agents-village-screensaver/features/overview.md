# All swarms at a glance (#481)

`overview=1` in the page's query shows every swarm at once: each is an
island, its shore red when something waits on you, the build is broken or a
deploy failed, amber when a house is blocked or stalled, and green otherwise,
with its working, idle and blocked houses counted. It comes back between
swarms while cycling; with `cycle=0` it stays, for a wall display.
`/village#*` opens it in a browser, and it is the last entry in the picker
("All swarms"). Clicking an island opens that village.
